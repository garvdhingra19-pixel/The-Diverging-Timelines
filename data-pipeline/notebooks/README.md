# Exploratory Data Notebooks

This folder holds climate analysis notebooks used to derive multi-decadal trends across the four landscapes:
- `climate_projections_exploration.py`: Python export of exploratory notebook modeling quadratic climate acceleration curves between 2025 and 2100.
- Data sources: IPCC AR6 SSP1-1.9 vs SSP5-8.5 projections, NOAA, and GBRMPA records.
