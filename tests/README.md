# Test Suites

This directory contains test suites covering:
- `unit/`: Zod schema validation, climate math interpolation algorithms, and state sanitization.
- `e2e/`: End-to-end user journeys verifying URL query string synchronization (`?place=...&year=...&scenario=...`).
- `a11y/`: Accessibility auditing for keyboard navigation, screen reader ARIA roles, color contrast, and touch targets.
