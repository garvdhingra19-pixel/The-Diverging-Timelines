# Visual Assets Directory

This directory stores optimized images (WebP and AVIF formats) for the climate landscapes:
- `mumbai.webp` / `mumbai.avif`: Mumbai coastline, Marine Drive promenade, and mangrove estuary
- `arctic.webp` / `arctic.avif`: Arctic tidewater glacier and sea ice expanse
- `amazon.webp` / `amazon.avif`: Amazon rainforest canopy and fluvial river systems
- `great-barrier-reef.webp` / `great-barrier-reef.avif`: Great Barrier Reef coral formations and marine lagoon
